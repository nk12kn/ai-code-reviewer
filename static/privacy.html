Privacy Policy & Data Processing Disclosure

Effective Date: September 21, 2026 • Last updated: September 2026

This Privacy Policy provides an accurate, straightforward explanation of how the AI Code Reviewer & Security Auditor application handles user input, source code submissions, web traffic, and advertising cookies.

1. How Your Source Code is Processed

When you paste source code or upload a file to the interactive scanner:

  • In-Memory Processing: Your submitted code snippet is sent via an HTTP POST request to our FastAPI backend (`/api/scan` or `/api/scan/file`). The code is held in server RAM during parsing, AST tree traversal, and heuristic evaluation.
  • No Database Storage: The application does not maintain a persistent database (such as PostgreSQL, MySQL, or MongoDB) to record or archive your submitted source code snippets or filenames. Once the HTTP response containing the audit findings is delivered to your browser, the code snippet is freed from application memory according to Python's garbage collection cycle.
  • Hosting & Server Logs: Like virtually all web applications hosted on cloud infrastructure (such as Render or containerized environments), standard web server access logs are generated. These logs record technical request metadata (such as your IP address, HTTP method, request path, timestamp, user agent string, and HTTP status code). Standard logs do not log request payload bodies by default, but diagnostic or debugging logs may temporarily record request sizes or error traces.

2. Optional External AI Providers & API Keys

The scanner functions completely offline using its built-in rule engine by default. If you choose to enable the optional deep semantic AI feature:

  • Local Storage: Any API key you provide (e.g. Google Gemini or OpenAI) is stored solely in your local browser's localStorage. It is not saved to any database on our servers.
  • Third-Party Transmission: When you execute a scan with AI enabled, your code snippet and API key are passed from the backend directly to the chosen provider's official API endpoint. That transmission is governed by the respective provider's terms and privacy policies (e.g. Google Cloud Terms or OpenAI API Platform Terms).

3. Cookies and Google AdSense Advertising

This website displays advertisements served by Google AdSense to help fund hosting and maintenance.

  • Third-party vendors, including Google, use cookies to serve ads based on a user's prior visits to this website or other websites on the internet.
  • Google's use of advertising cookies enables it and its partners to serve ads to users based on their visit to this site and/or other sites on the Internet.
  • Users may opt out of personalized advertising by visiting Google Ads Settings. Alternatively, users can opt out of third-party vendor cookies for personalized advertising by visiting www.aboutads.info.
  • Advertisements are strictly restricted to substantive educational content zones and are not placed on empty interactive editor views, loading screens, or error dialogs.

4. Contact Information & Inquiries

If you submit an inquiry or security report through our Contact page, the information you provide (your name, email address, subject, and message text) is used solely to respond to your communication, clarify reported issues, or coordinate responsible vulnerability disclosures. We do not sell or rent contact information to third parties.

5. Scope & Clear Disclosures

While we design the service to be lightweight and minimize unnecessary data collection by avoiding persistent storage of submitted code, please note: this is a developer-focused web utility. We do not hold formal SOC2, ISO 27001, HIPAA, or other organizational security certifications. If your organization handles strictly classified code, trade secrets, or highly regulated data, we recommend reviewing our architecture or running your code through internal self-hosted tools.

6. Updates to this Policy

We may update this Privacy Policy from time to time to reflect modifications in application functionality, hosting infrastructure, or regulatory guidelines. Any updates will be reflected directly on this page with a revised effective date.
